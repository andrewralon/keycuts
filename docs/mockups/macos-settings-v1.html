What changes from Windows

  • Run keycuts in Terminal (5.4, the PATH row) replaces nothing; on Windows PATH is offered only in the welcome panel. On: the marked block in ~/.zprofile (or ~/.bash_profile), as keycuts path add; off removes it, leaving the rest of the file byte for byte. Its note follows the state:
    • "Adds the folder to PATH in ~/.zprofile." (off, or on and in place)
    • "It’s already on PATH, so there’s nothing to add." (on, and set by something else: the switch is on and disabled)
    • "fish doesn’t read ~/.zprofile. Add the folder to PATH in its own settings." (fish, nushell: disabled)
    • "Open a new Terminal window to use it." for 6 s after turning it on.
  • Finder Quick Action replaces "Right-click context menus" (Phase 7 installs it; until then the row is there and the switch does nothing but save). It shows the actual state, as the Windows row does.
  • Use $HOME in paths: the same setting as "Use environment variables in paths"; macOS has only $HOME, so it says so.
  • Run box (new section, 6.2 and 6.5). Shortcut is a key recorder: click it, press the keys, Esc cancels, Delete clears (no hotkey). A shortcut must include ⌘ or ⌃ (macOS 15). Open at login is SMAppService's state (notFound reads as off); its note says keycuts stays in the menu bar and roughly what that costs (correction 5).
  • Icon: the Dock icon while keycuts runs. Finder and Launchpad keep the bundle's own icon, which can't change without breaking the signature. Transparent icon background is gone on macOS: the Dock has no tile behind the icon, so there is nothing to turn off.
  • Theme: System follows macOS, Increase Contrast included (high contrast, Phase 5.4).

  • The box: a borderless window, 600 wide, a third of the way down the active screen, above every window (also over full-screen apps). One text box (20, the keycap at 28 beside it) and up to 6 rows from RunBoxMatcher: exact name, then prefix, then the rest by runs and last run. Each row: name (SemiBold), type badge, target, runs. Nothing typed shows nothing (the box is just the text field).
  • Keys: Return runs the selected row (/bin/sh through IDesktop, detached) and hides; Tab completes the name to the selected row's (the gray "ail"); ↑ ↓ move the selection; Esc hides. Hiding hands focus back to the app that was in front. Clicking a row runs it; clicking outside hides the box.
  • No match: one row, "Create “name”…", which opens the main window on the creator with the name filled in.
  • Accessibility: the text box is named "Run a keycut"; the list is a list box whose selection VoiceOver reads ("gmail, URL, https://mail.google.com, 42 runs"); the hint line is text, not buttons.
