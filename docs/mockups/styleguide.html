Writing

  • Lowercase: tabs (creator, manager, settings), dialog titles (edit keycut) and button text (save, show welcome, add to PATH). Sentence case for the rest: “Edit in Notepad”, “Ask before replacing a keycut”.
  • keycuts and keycut are always lowercase, even first in a label: “keycut name”.
  • Keys: Ctrl+Shift+E, Shift+F2, Win+R. In a tooltip: “Undo the delete (Ctrl+Z)”.
  • Ellipsis … only for a command that asks for more (File…, Edit…) and work in progress (Saving…).
  • No period on labels, buttons, headings; periods on sentences. Typographic ’ and “ ” in the app.
  • The automation name starts with the visible label; extra words go to HelpText.
  • Errors: what happened, then what to do. “Couldn’t save to the output folder. Check Settings.”
