# ShortcutFile parse of every file in tests/corpus/legacy
# Values are wrapped in | | so leading and trailing spaces show.
# Notes below cover the known wrong answers.

## edge-cases/command-type.bat
Shortcut:    |command-type|
Type:        Command
Destination: |ipconfig /all|
OpenWithApp: <null>
Command:     |START "" /B "ipconfig /all"|
Description: ||
Note:        Parsed as File, not Command: the file pattern is tried first and matches any quoted START (#93).
