Two window sizes — v1

The window has two sizes. Small is today’s Creator: 600 wide, as tall as its content, fixed. Large is today’s Manager: 960 × 700 by default, resizable down to 720 × 480, and still never maximized. The Creator uses small; the Manager and Settings share large. Settings never grows the window: it takes whatever size the Manager last had and fits its content into it, either in two columns (C) or one column that scrolls (D). The Manager keeps the Creator’s fields as one row on top — Target, Name, Description, left to right — so you can add a keycut without leaving the list.
