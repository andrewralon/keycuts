# keycuts — Gameplan

Updated 2026-11-10. This replaces the original 44-issue plan, which is still in git history. Most of that plan's Phase 1 and Phase 2 shipped, and the UI redesign (KC-01 to KC-20, `docs/tickets/`) made most of its Phase 3.3 moot by replacing the WPF GUI and the Batmanager app.

9. **#118: signing. Waiting on the user's decision.** It needs a certificate, so it's a cost decision before it's an engineering one.
   - **Why:** a downloaded unsigned MSI gets SmartScreen's "Windows protected your PC" with an unknown publisher, and Smart App Control (on some Windows 11 machines) can block an unsigned app outright. Signing names the publisher, but a new certificate still builds SmartScreen reputation over time. SmartScreen only checks downloaded files, so it doesn't affect local builds. Smart App Control checks every app it runs, so when it's enforcing it can block a local build too.
   - **Options (2026-11-10):** SignPath Foundation, free for open source but it needs an OSI license in the repo (there's none yet) and shows SignPath Foundation as the publisher; Azure Artifact Signing (formerly Trusted Signing), about $9.99 a month, for individuals in the US or Canada, billed from account creation; an OV certificate, a few hundred dollars a year plus a hardware token or cloud key store; or on hold. An Apple Developer account doesn't help here: it covers macOS signing and notarization (#106).
   - **The issue text is stale:** `keypaste.exe` is now `keypaste.cmd`, which Authenticode can't sign, and `master` is now `main`.

## Rules that still apply

- **Never move two variables in one commit.** An emitter or parser change must show up as a reviewed diff in `keycuts.Tests/Characterization/Snapshots/*.verified.txt`. When a snapshot test fails, it writes a `.received.txt` next to the snapshot; if the change is intended, copy it over the `.verified.txt` in the same commit.
- **Never edit or delete corpus files**; add new ones (`tests/corpus/legacy/README.md`).
- **Add an interface only when a fix needs one to be testable**, the way `IPathUpdater`, `IClassesStore` and `IKeycutActions` were added.

## Decisions made on 2026-11-09

| Issue | Decision | Why |

| #91 REM precedence | The REM `<type>` and `<destination>` win over the launch command, even when they disagree. | The parser only feeds display and checks; the `.bat` still runs its own command, and `Command` keeps the full line.
