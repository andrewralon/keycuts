Output folder: User / System — v2

v1 redrawn for the tabbed window now on develop (1.6.1): Settings is the gear tab at 960 × 544, in two columns, with no heading and no Save button. The User / System choice sits on the Output folder label’s line, as Theme’s choices do. A change asks first in the Confirm dialog, as restore defaults does, and that dialog now also shows what the sync would do, so there is no separate preview step.

What changed from v1, and why
  • No cards, no Apply. Two radio cards and an “Unsaved change” box would not fit the left column (it has about 150 to spare) and Settings has no Save step. Choosing a side, or committing a new path, asks at once, the way restore defaults does: it stores immediately, so it asks first. Cancel puts the choice back.
  • The other side’s path stays visible in the helper line (“The System folder is …”), so nothing is ever lost from view.
  • Preview folded into Confirm. One dialog: from, to, and what a sync would do. Buttons follow the style guide: the secondary action that isn’t cancel at the left edge, cancel then the primary at the right, all lowercase.
  • The result stays in Settings as an inset panel under the folder box (there is no status line on this screen), with undo sync and open backups, until you undo or dismiss it.
  • Open: to change the other side’s path you switch to it first, so a first-time custom System folder can ask twice. Say if you want to edit it without switching.
  • Unchanged: restore defaults still never touches the folder, and now also leaves the choice and both paths alone.
  • Drawn in the light palette and without the torn corner. The tab bar and the two columns follow docs/styleguide.md.
